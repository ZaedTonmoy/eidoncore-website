Domain Setup & Verification Checklist
Step 1: Add the DNS records
At your DNS provider (e.g. Cloudflare, GoDaddy, Route53)

Add the CNAME record below. If your provider expects the full hostname (AWS Route53, Google Cloud DNS), use the Exact Hostname (FQDN). If it manages the root zone (Cloudflare, GoDaddy, Namecheap), use the Host Record Name.

Record Type:
CNAME
Exact Hostname (FQDN):
portal.youragency.com
Host Record Name:
portal (in zone: youragency.com)
Target / Value:
cname.********************.eidon-dns.com
Managing a delegated sub-zone?
Ownership record (TXT)

Every workspace uses the same CNAME target, so this TXT record proves the domain is yours. Verification needs both records. Leave it in place after verification.

TXT
Exact name (FQDN)
_eidon-verify.portal.youragency.com
